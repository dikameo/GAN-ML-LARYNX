[12] Wang dkk. - Radiomics-GenAI  (REFERENSI UTAMA, basis S3 dan S4)
  https://github.com/DylanChrisWong/Radiomics-GenAI
  Isi: 1 notebook Colab (Radiomics_GenAI.ipynb, 227 sel), LICENSE. Commit terakhir 2026-08-12.
  Temuan penting untuk skenario:
  - "GAN" mereka adalah CTGAN (library ctgan, model tabular): batch_size=50, epochs=100 (varian 200 ada di komentar), sampel sintetis = 50% dari ukuran data yang dilatih.
  - Split: StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42), grup = Patient_ID (diambil dari awalan nama file).
  - Scaler (MinMax) dan LASSO difit DI DALAM tiap lipatan (tidak bocor lewat tahap ini). SMOTE: random_state=42, sampling_strategy='auto'.
  - LASSO di kode: alpha=0.01 (juga ada percobaan LassoCV). Proposal menulis lambda=0,001 -> BERBEDA, perlu diputuskan mana yang direplikasi.
  - Fitur radiomik TIDAK diekstrak di notebook: dibaca dari x_train.csv, x_test.csv, y_train.csv, y_test.csv di Google Drive penulis (tidak ada di repo). Kode PyRadiomics tidak ada (0 hasil). Untuk S3/S4 kamu harus mengekstrak 104 fitur sendiri atau menghubungi penulis.
  - Model: SVM linear, KNN, Random Forest, LDA. Tidak ada bootstrap, tidak ada AUROC interval.
  - Notebook banyak berisi kode percobaan yang dikomentari; jalur file hard-coded ke /content/drive/...

[08] Kiani Kalejahi dkk. - Gated MIL untuk CE-NBI laring  (DATASET SAMA, split pasien siap pakai)
  https://github.com/b-kiani/Multi-Instance-Learning-for-Robust-Malignancy-Classification-in-Laryngeal-Contact-Endoscopy
  Isi: 2 notebook (ENT.ipynb, Laryngeal Lesion Detection.ipynb), patient_folds/ (fold1..5 train/val), _challenge2_artifacts/ (manifest, split standar, split pergeseran resolusi, resolution_counts, patients_meta). Commit terakhir 2026-03-03.
  Temuan:
  - Backbone ResNet50, LR 5e-5. Pergeseran domain = latih pada resolusi mayoritas 1280x1008, uji pada resolusi lain ("minor").
  - Jumlah citra per resolusi: 1280x1008=6714, 868x540=1476, 1736x1080=1266, 720x544=1153, 1842x1080=548 (total 11.157).
  - PERINGATAN: total di repo ini 11.157 citra, 151 jinak / 59 ganas (7.715 / 3.442). Datasetmu dan proposal: 11.144 citra, 150 jinak / 60 ganas (7.657 / 3.487). [10] Huang dkk. - ROI-guided CycleGAN laring  (basis loss berbobot ROI)
  https://github.com/lin521045/roi-guided-cyclegan-larynx
  Arsip: https://doi.org/10.5281/zenodo.20094409
  Isi: fork pytorch-CycleGAN-and-pix2pix, hanya README (204 KB). Commit 2026-03-05.
  Temuan:
  - ROI dipakai sebagai bobot pada cycle-consistency loss: loss = |rec_A - real_A| * (1 + lambda_roi * mask). Default lambda_roi=0.0 hard-coded di models/cycle_gan_model.py (nilai contoh 10.0).
  - Ini loss rekonstruksi. Proposalmu memindahkan bobot ROI ke diskriminator kedua D_roi pada StyleGAN2-ADA -> adaptasi, bukan replikasi (proposal sudah mengakui ini).
  - Cuma README yang terbaca di klon dangkal; kode lengkap dan bobot ada di arsip Zenodo (belum dibuka).

======================================================================
E. TEMUAN SKENARIO (rangkuman pembacaan)
======================================================================
1. Dataset lokal terverifikasi: Benign 7.657 citra/150 pasien, Malignant 3.487 citra/60 pasien, total 11.144 citra, 1,4 GB. Sesuai Tabel 3.2 proposal.

2. S7 (uji pergeseran resolusi) - syarat proposal tidak terpenuhi bila tiap resolusi dihitung terpisah.
   Syarat proposal: minimal 10 pasien ganas DAN 10 pasien jinak per kelompok. Setiap pasien hanya punya satu resolusi (dihitung dari manifest repo [08]):
     resolusi     jinak  ganas   citra
     1280x1008     101    36     6714   <- memenuhi
     868x540        19     9     1476   <- gagal (ganas 9)
     1736x1080      10     9     1266   <- gagal (ganas 9)
     720x544        14     3     1153   <- gagal (ganas 3)
     1842x1080       7     2      548   <- gagal (jinak 7, ganas 2)
   Digabung jadi "minor" (4 resolusi): 50 jinak + 23 ganas = 73 pasien -> memenuhi. Ini sama dengan skema [08] (latih 1280x1008, uji minor).
   Catatan: proporsi ganas tiap resolusi berbeda jauh (1736x1080 = 49% ganas, lainnya 22-33%), jadi resolusi bercampur dengan kelas/akuisisi lain. Angka ini dari manifest [08] (selisih 1 pasien dengan datamu) dan harus diaudit ulang dari gambar lokal sebelum dipakai.

3. Replikasi Wang dkk. (S3/S4): "GAN" = CTGAN tabular; fitur radiomik tidak tersedia di repo; alpha LASSO di kode (0,01) beda dengan proposal (0,001).

4. Beban komputasi: 10 lipatan (5 lipatan x 2 ulangan). GAN dilatih per lipatan: 10 (dengan ROI) + 10 (tanpa ROI, S5) = 20 pelatihan GAN, lalu pelatihan Swin-T untuk S1, S2, S5 (3 rasio), S6 (3 rasio) = sekitar 80 pelatihan klasifikator, ditambah S7. Dataset sendiri kecil (1,4 GB; 11 ribu citra 256x256 muat di RAM). Kebutuhan paralel ada di jumlah eksperimen, bukan ukuran data.
